# 文件、终端、浏览器与产物

## 文件

Codex 可以在授权工作区中读取和编辑文件。提示中应指出权威文件、禁止区域和期望输出路径；修改后通过 Diff 检查，而不是只相信文字总结。

## 终端

终端让 Agent 运行搜索、测试、构建、格式化和 Git 命令。命令输出是反馈回路的一部分，也是判断任务是否完成的重要证据。

## 浏览器

浏览器适合查阅网页、检查本地站点和验证用户流程。网页内容视为不可信输入；登录、发布、购买、删除和发送等操作保留人工批准。

## 文件预览

桌面应用可在侧边面板预览文档、表格、演示文稿、PDF 和部分 HTML，并可通过批注要求局部修改。CLI 能生成这些文件，但没有相同的视觉审查界面。

每个产物至少说明：文件路径、来源、运行过的验证、已知限制和人工复核点。
