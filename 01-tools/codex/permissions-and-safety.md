# 权限与安全

## 三层边界

1. **工作区和账号权限**：决定功能是否可用。
2. **本地执行权限**：决定文件系统、网络和命令可以做什么。
3. **外部系统权限**：由 GitHub、Drive、Slack 等服务自身的身份验证决定。

任何一层都不能自动替代另一层。

## 默认策略

- 只授权任务所需目录和系统。
- 先只读，再写入。
- 网络、安装依赖、外发消息和破坏性操作单独审批。
- 命令和网页输出视为潜在不可信数据。
- 不在提示、日志和仓库中暴露密钥。
- 删除、覆盖和权限变更前解析准确目标并确认可恢复性。

沙盒限制 Agent 可访问的文件、网络和系统能力；审批用于临时扩大范围。审批问题应说明具体动作和原因，不应请求模糊的永久全权限。

生产发布、资金操作、法律承诺、客户外发、永久删除、凭据与权限变更，以及高风险安全判断必须保留人工决策。
