# Projects 与 Threads

## 心智模型

- **Project** 绑定长期工作空间、仓库或文件夹。
- **Thread** 对应一个具体成果，保留自己的对话和执行过程。
- 同一 Project 可以有多个 Thread，但每个 Thread 应保持单一结果导向。

用成果命名 Thread，例如“补齐登录测试”“审查支付迁移”，不要使用“继续”“新任务”等无法检索的标题。活跃任务保持可见，完成后归档。

## 选择操作

| 需求 | 操作 |
| --- | --- |
| 延续同一成果 | 继续原 Thread |
| 从当前历史探索另一方案 | Fork |
| 完全不同的交付物 | 新 Thread |
| 在另一个环境继续同一任务 | Handoff |
| 已完成且暂时不用 | Archive |

固定、重命名和归档只改变组织方式，不会自动增加模型上下文。长期规则仍应写入仓库，实时状态仍应重新检查。
