# ChatGPT

本目录覆盖 ChatGPT 中从快速对话到持续工作的主要入口。功能名称、可用范围和界面会变化，选择时应从任务结果出发，而不是从按钮出发。

## 功能地图

| 主题 | 最适合解决的问题 | 知识卡 | 状态 |
| --- | --- | --- | --- |
| Projects | 长期目标如何共享上下文 | [`projects.md`](projects.md) | 第一轮完成 |
| Memory | 偏好和历史如何跨对话延续 | [`memory.md`](memory.md) | 第一轮完成 |
| Library | 文件如何查找、复用和管理 | [`library.md`](library.md) | 第一轮完成 |
| Search | 如何获得可追溯的最新公开信息 | [`search.md`](search.md) | 第一轮完成 |
| Work | 如何委托多步骤、可交付的工作 | [`work.md`](work.md) | 第一轮完成 |
| Browser | 如何在网页中研究、验证和操作 | [`browser.md`](browser.md) | 第一轮完成 |
| Plugins | 如何连接工具并复用工作流 | [`plugins.md`](plugins.md) | 第一轮完成 |
| Scheduled | 如何定期运行、监控和提醒 | [`tasks.md`](tasks.md) | 第一轮完成 |
| Codex | 何时切换到本地工程代理 | [`codex.md`](codex.md) | 第一轮完成 |

## 快速选择

- 简短问答、解释、改写：使用 **Chat**。
- 多次返回同一目标：使用 **Project**。
- 明确交付物、涉及多个来源或工具：使用 **Work**。
- 需要本地仓库、终端、Git 和测试：使用 **Codex**。
- 需要周期性重复：使用 **Scheduled** 或 Codex Automation。

完整边界见 [`Chat、Work 与 Codex 选择指南`](../../05-comparisons/chat-work-codex.md)。
