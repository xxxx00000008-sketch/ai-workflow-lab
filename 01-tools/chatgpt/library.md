# ChatGPT Library

> 最近验证：2026-09-19

## 定位

Library 是已上传、生成或连接文件的查找与复用入口。它降低重复上传成本，但不自动把所有文件变成当前对话的有效上下文。

## 推荐工作法

1. 使用可搜索、可理解的文件名。
2. 为易变化资料加日期或版本。
3. 从 Library 选取当前任务真正需要的文件。
4. 在提示中说明文件角色、权威程度和期望产物。
5. 完成后把最终文件放回正式存储或版本库。

## 边界

- 文件出现在 Library，不代表模型每次都会自动引用它。
- 连接文件仍受原服务权限控制。
- Library 不是 Git、文档审批系统或备份系统。
- 删除、保留和训练使用受账号类型、数据控制和工作区政策影响。

## 文件提示模板

> 使用附件 A 作为事实来源，附件 B 只作为格式参考。输出一份可审查的文档；遇到冲突时列出冲突，不要自行合并数字。
