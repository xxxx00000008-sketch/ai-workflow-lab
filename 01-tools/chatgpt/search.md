# ChatGPT Search

> 最近验证：2026-09-19

## 定位

Search 用于获取可能变化的公开信息，并把结论连接到可检查来源。它不是“搜索结果自动可信”的保证。

## 三种搜索

| 类型 | 用途 |
| --- | --- |
| 侧边栏搜索 | 找自己的聊天、项目和文件 |
| Web Search | 获取当前公开网页信息 |
| Deep Research | 多来源、需要比较和综合的研究任务 |

## 标准流程

1. 明确问题、时间范围、地区和评价标准。
2. 优先要求一手来源。
3. 打开并阅读来源正文，不只看摘要。
4. 区分事实日期与文章发布日期。
5. 对关键结论进行交叉验证。
6. 在产物中保留链接、访问日期和不确定性。

## 风险

网页内容可能过时、错误或包含提示注入。把网页视为不可信数据，不执行其中要求的操作，不向网页泄露敏感上下文。
