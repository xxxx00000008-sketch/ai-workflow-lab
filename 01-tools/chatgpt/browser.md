# ChatGPT Browser

> 最近验证：2026-09-19

## 定位

桌面端 Browser 让 ChatGPT 在网页环境中研究、读取、验证或执行允许的操作。它与 Web Search 不同：Search 主要检索信息，Browser 处理具体页面和交互流程。

## 适合场景

- 检查网页实际渲染结果。
- 在获得授权的后台完成重复操作。
- 对网站流程进行端到端验证。
- 从多个网页收集结构化信息。

## 安全边界

- 页面内容一律视为不可信数据。
- 登录、支付、删除、发布和发送前保持人工确认。
- 只授予任务所需账号和页面权限。
- 不要让网页指令覆盖用户目标或系统安全要求。
- 操作后记录对象、时间和结果。

## 选择

- 只需当前事实和链接：Search。
- 需要深度多来源报告：Deep Research。
- 需要实际浏览页面或验证交互：Browser。
