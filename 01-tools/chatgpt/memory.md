# ChatGPT Memory

> 最近验证：2026-09-19

## 定位

Memory 用于让 ChatGPT 在后续对话中参考有帮助的用户偏好和历史。它适合减少重复说明，不适合作为需要逐字准确、可审计的项目数据库。

## 两类连续性

- **已保存的记忆**：较稳定的偏好、背景和习惯。
- **对话历史引用**：根据过去对话提供相关上下文，具体行为受账号、工作区和设置影响。

Project 还可能提供默认 memory 或 project-only memory。后者强调项目内外上下文隔离；关键状态仍应写入项目文件。

## 适合保存

- 语言、格式和沟通偏好。
- 长期角色和稳定目标。
- 不敏感、未来经常复用的背景。

## 不应依赖 Memory 保存

- 密钥、身份证明、健康或客户敏感数据。
- 精确数字、合同条款、版本号和最新项目状态。
- 必须可追溯和可回滚的决策。

## 使用原则

1. 把 Memory 当作便利层，不当作事实层。
2. 关键任务开始时仍明确目标和约束。
3. 定期检查、纠正或删除过期记忆。
4. 项目事实进入仓库或权威文件。

## 风险

错误或过期记忆可能影响后续回答；不同方案和工作区设置可能限制功能。处理敏感项目时，应检查当前设置，并优先使用明确的资料边界。
