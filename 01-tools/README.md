# Tools

记录具体 AI 工具的能力、入口、适用场景、限制与风险。产品行为可能变化，正文应注明测试日期和环境，并分别提供：

- **入门用法**：让第一次使用的人按最短步骤完成一个具体任务。
- **高阶用法**：说明能力组合、规则沉淀、批量或自动化、人工审批和失败恢复。

高阶不等于提示词更长，而是工作方式从一次操作升级为可复用系统。
