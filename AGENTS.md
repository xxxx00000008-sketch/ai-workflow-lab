# AGENTS.md

## Project purpose

This repository is a Chinese-first, evidence-based knowledge base about practical AI workflows. Prefer durable methods over feature-list documentation.

## Working rules

- Read `README.md`, `ROADMAP.md`, and the nearest topic README before editing.
- Separate sourced facts, experimental observations, and opinions.
- Add a test date and environment to claims about fast-changing product behavior.
- Prefer official primary sources. Do not fabricate citations or test results.
- Never commit secrets, personal data, private conversations, or unredacted account screenshots.
- Use lowercase kebab-case filenames and relative Markdown links.
- For a new feature study, pair a knowledge card in `01-tools/` with evidence in `07-experiments/` when possible.
- Keep changes focused and update `CHANGELOG.md` when they materially affect published content or structure.

## Validation

- Verify that relative links resolve.
- Review headings and tables in rendered Markdown.
- Search for accidental secrets and placeholder claims before committing.
