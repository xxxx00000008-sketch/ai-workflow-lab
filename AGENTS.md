# AGENTS.md

## Project purpose

This repository is a Chinese-first, evidence-based lab for turning current AI product capabilities into reproducible work methods. It has two equal axes: product capabilities and real work scenarios. Prefer durable methods and measured outcomes over feature-list documentation.

## Working rules

- Read `README.md`, `ROADMAP.md`, and the nearest topic README before editing.
- Separate sourced facts, experimental observations, and opinions.
- Add a test date and environment to claims about fast-changing product behavior.
- Prefer official primary sources. Do not fabricate citations or test results.
- Never commit secrets, personal data, private conversations, or unredacted account screenshots.
- Use lowercase kebab-case filenames and relative Markdown links.
- For a new feature study, pair a knowledge card in `01-tools/` with evidence in `07-experiments/` when possible.
- Classify content as an official capability note, experiment, workflow, case, or reusable asset. Do not present a proposal or unexecuted procedure as a verified result.
- A real case must include a concrete input, actual execution, inspectable output, human approval points, limits, and at least one comparison of time, quality, cost, rework, or risk.
- Compare traditional work, one-off AI assistance, standardized workflow, and automation when the comparison is meaningful.
- Treat ChatGPT Project + Codex Project as one composition pattern, not the universal project architecture.
- A website is a publication or delivery channel, not an objective unless the task explicitly concerns a site.
- Keep changes focused and update `CHANGELOG.md` when they materially affect published content or structure.

## Validation

- Verify that relative links resolve.
- Review headings and tables in rendered Markdown.
- Search for accidental secrets and placeholder claims before committing.
