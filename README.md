# AI Workflow Lab

通过真实项目和真实工作场景，研究 AI 工具如何改变个人工作、软件研发、内容创作和独立开发。

这里不是某个 AI 产品的按钮说明书，也不是提示词堆积仓库。我们关注的是：在什么场景下选择什么工具，如何把工具组合成稳定、可验证、可复用的工作流，以及这些实践背后的通用原理。

> 当前阶段：**V0.1 — ChatGPT Deep Dive**

## V0.1 学习路线

`Projects → Memory → Library → Search → Work → Browser → Plugins → Tasks → Codex`

每个主题都遵循同一研究闭环：

`官方资料 → 提出问题 → 设计实验 → 实际测试 → 记录结果 → 抽象原理 → 编写知识卡 → 提炼工作流 → 形成案例`

详细范围与验收标准见 [`ROADMAP.md`](ROADMAP.md)。研究从 [`ChatGPT Projects`](01-tools/chatgpt/projects.md) 开始。
