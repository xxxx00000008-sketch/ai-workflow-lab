# AI Workflow Lab

通过真实任务、可复现实验和效率对比，研究 ChatGPT、Codex、Claude Code 等 AI 产品如何进入实际工作，并把有效方法沉淀为可复用的工作流、模板、Skills 与自动化系统。

这里不是某个 AI 产品的按钮说明书，也不是提示词堆积仓库。我们关注的是：在什么场景下选择什么工具，如何把工具组合成稳定、可验证、可复用的工作流，以及这些实践背后的通用原理。

项目同时沿两条轴推进：

- **产品能力轴**：当前功能、限制、选择方式和产品组合
- **工作场景轴**：研究、写作、开发、内容生产、项目管理、数据处理、知识管理和开源运营

产品功能说明只是基础。最终交付必须继续走向实验、工作流、真实案例和可执行资产。完整定位与验收标准见 [`project-charter.md`](project-charter.md)。

> 当前阶段：**V0.1 — ChatGPT & Codex 能力基线完成；V0.2 — 真实工作流验证进行中**

## 研究闭环

`官方资料 → 能力卡 → 可复现实验 → 工作流 → 真实案例 → 模板 / Skill / Automation`

每项工作还要比较：

`传统手工 → 单次 AI 协作 → 标准化流程 → 自动化流程`

详细范围与验收标准见 [`ROADMAP.md`](ROADMAP.md)。从 [`ChatGPT 功能地图`](01-tools/chatgpt/) 或 [`Codex 桌面端地图`](01-tools/codex/) 开始，也可以直接查看 [`Chat、Work 与 Codex 选择指南`](05-comparisons/chat-work-codex.md)。

如果你更关心“实际工作中怎么提效”，直接阅读 [`ChatGPT + Codex 实际工作提效手册`](03-workflows/chatgpt-codex-productivity-playbook.md)，其中按研究、会议、开发、写作和周报场景比较传统做法、AI 协作和自动化流程。

**ChatGPT Project 负责研究与写作、Codex Project 负责本地文件与交付**，只是适合长期知识库的一种组合模式，不是本项目的唯一主线。
