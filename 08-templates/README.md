# Templates

这些模板用于保证内容可验证、可复现，而不是统一文章外观。

- [`knowledge-card.md`](knowledge-card.md) — P1 官方能力卡或工具知识卡
- [`experiment.md`](experiment.md) — P2 可复现实验记录
- [`workflow.md`](workflow.md) — P3 已执行的端到端工作流
- [`case-study.md`](case-study.md) — P4 真实案例与传统/AI/自动化对比

复制模板后应删除无关提示，并把“状态”填写为真实情况。未完成实际执行的流程只能标为“方案”或“待验证”。
