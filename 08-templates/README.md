# Templates

这些模板用于保证内容可验证、可复现，而不是统一文章外观。

- [`knowledge-card.md`](knowledge-card.md) — A1 官方能力卡或工具知识卡
- [`experiment.md`](experiment.md) — A2 可复现实验记录
- [`workflow.md`](workflow.md) — A3 已执行的端到端工作流
- [`case-study.md`](case-study.md) — A4 单文档自动化案例，包含具体步骤和建议目录树

复制模板后应删除无关提示，并把“状态”填写为真实情况。实验、工作流和案例还应标明证据等级 `E0-E4` 与自动化成熟度 `M0-M4`。案例中的目录树只需写在文档中，不需要实际创建对应文件；未完成实际执行的案例标为“未验证”。
